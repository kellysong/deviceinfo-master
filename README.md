
## deviceinfo-master

设备信息查询

目的:

1. 轻量查看设备参数：提供免安装、无广告的设备信息查询功能，替代安兔兔等重型应用，快速获取核心硬件与系统信息。
2. 辅助 Android 屏幕适配：自动提取并展示屏幕适配所需的关键参数（如 sw 限定符、宽高限定符、屏幕密度等），并给出图片适配建议，帮助开发者快速完成适配方案。
